# Syncora — Required Study Materials

Only the topics needed to build Syncora.

## Core Learning List

| # | Topic | Level | What to Study |
|---|---|---|---|
| 1 | **TypeScript** | Must learn | Types, interfaces, type aliases, unions, generics, narrowing, utility types, async types |
| 2 | **React** | Must learn | Components, props, state, forms, effects, refs, custom hooks, composition |
| 3 | **Vite** | Basic | Project setup, environment variables, development/build workflow |
| 4 | **TanStack Router** | Must learn | File-based routing, dynamic/nested routes, layouts, params, search params, auth protection |
| 5 | **TanStack Query** | Must learn | Queries, mutations, query keys, caching, invalidation, pagination, optimistic updates, server state |
| 6 | **Zustand** | Basic–Intermediate | Stores, selectors, actions, TypeScript, client/UI state |
| 7 | **Tailwind CSS** | Must learn | Utility classes, layout, responsive design, typography, spacing, states |
| 8 | **shadcn/ui** | Must learn | Buttons, forms, dialogs, dropdowns, sheets, tables, command menu, avatars, badges, calendar |
| 9 | **Bun** | Basic | Runtime, package management, scripts, `bunx`, environment variables |
| 10 | **Hono** | Must learn | Routes, context, middleware, request/response, errors, CORS, auth middleware |
| 11 | **Zod** | Must learn | Schemas, objects, enums, optional/nullable, `refine`, `parse`/`safeParse`, validation |
| 12 | **PostgreSQL / SQL** | Must learn | Tables, PK/FK, joins, constraints, indexes, transactions, basic queries |
| 13 | **Supabase Auth** | Must learn | Signup, login, logout, sessions, verification, password reset, auth state |
| 14 | **Supabase RLS** | Must learn | `auth.uid()`, policies, workspace-level access, defense in depth |
| 15 | **Supabase CLI + Migrations** | Must learn | `init`, local development, migration creation, reset, push, generated TypeScript types |
| 16 | **Supabase Realtime** | Learn later | Broadcast, Presence, Postgres Changes, channels, subscriptions, authorization |
| 17 | **WebSocket Fundamentals** | Conceptual | Persistent connections, handshake, messages, lifecycle, reconnects, authentication |
| 18 | **Git + GitHub** | Must learn | Branches, commits, push/pull, PRs, conflicts, merge/rebase basics |
